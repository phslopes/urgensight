# Skill: graphify

Esta skill permite inspecionar ou regenerar o Knowledge Graph estrutural do repositório.

## Uso
- Para atualizar o grafo: `make graphify`
- Para consultar conexões de um símbolo: inspecione `graphify-out/` ou execute consultas determinísticas no grafo.
